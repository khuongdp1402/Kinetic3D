# Storefront UI Implementation

## Goal
Build the customer-facing Next.js storefront including a sticky header with Meilisearch, Hero Carousel, and a Product Grid with 3D tilt effects, strictly following the Cyber-Tech/Modern Minimalist aesthetic.

## Tasks

```xml
<task id="install_deps">
  <description>Install frontend dependencies for animation, search, and icons</description>
  <read_first>
    - src/Kinetic3D.WebUI/package.json
  </read_first>
  <action>
    Run: `npm install framer-motion clsx tailwind-merge meilisearch react-parallax-tilt lucide-react embla-carousel-react embla-carousel-autoplay` inside `src/Kinetic3D.WebUI`.
  </action>
  <acceptance_criteria>
    - `src/Kinetic3D.WebUI/package.json` contains `framer-motion`, `meilisearch`, `react-parallax-tilt`, `lucide-react`, `embla-carousel-react`, and `embla-carousel-autoplay`.
  </acceptance_criteria>
</task>

<task id="setup_styling">
  <description>Configure global styling and Next.js config for the Obsidian Black / Cyber-Tech aesthetic</description>
  <read_first>
    - src/Kinetic3D.WebUI/src/app/globals.css
    - src/Kinetic3D.WebUI/next.config.ts
  </read_first>
  <action>
    1. Update `next.config.ts` to allow images from `localhost` (for MinIO).
    2. Update `globals.css` to use background `#0B0B0B` (Obsidian Black) and text `#F3F4F6`.
    3. Add Tailwind custom utilities if needed for cyan (`#00FFFF`) and neon orange (`#FF5F1F`) accents.
  </action>
  <acceptance_criteria>
    - `next.config.ts` contains `remotePatterns` for `localhost`.
    - `globals.css` contains `@theme` or root variables setting background color to `#0B0B0B`.
  </acceptance_criteria>
</task>

<task id="build_header_search">
  <description>Implement Header and Meilisearch Integration</description>
  <read_first>
    - src/Kinetic3D.WebUI/src/components/storefront/Header.tsx
    - src/Kinetic3D.WebUI/src/components/storefront/Search.tsx
  </read_first>
  <action>
    1. Create `src/components/storefront/Search.tsx`: Uses `meilisearch` JS client to connect to `http://localhost:7700`. Displays an icon that, when clicked, expands a full-width search bar with dark overlay. Results show thumbnail, name, and price.
    2. Create `src/components/storefront/Header.tsx`: Sticky navigation bar containing Logo, Links, and the `Search` component.
  </action>
  <acceptance_criteria>
    - `Header.tsx` exists and exports a sticky header.
    - `Search.tsx` exists, imports `MeiliSearch`, and contains search logic.
  </acceptance_criteria>
</task>

<task id="build_hero_carousel">
  <description>Implement Hero Carousel with video/image mix</description>
  <read_first>
    - src/Kinetic3D.WebUI/src/components/storefront/HeroCarousel.tsx
  </read_first>
  <action>
    Create `HeroCarousel.tsx` using `embla-carousel-react` and `embla-carousel-autoplay`.
    The carousel should have a horizontal slide transition.
    Provide mock/placeholder slides: Slide 1 is a video loop, Slides 2-4 are high-quality placeholder images.
  </action>
  <acceptance_criteria>
    - `HeroCarousel.tsx` exists and uses `useEmblaCarousel` with `Autoplay`.
  </acceptance_criteria>
</task>

<task id="build_product_grid">
  <description>Implement Product Card and Grid with 3D Tilt</description>
  <read_first>
    - src/Kinetic3D.WebUI/src/components/storefront/ProductCard.tsx
    - src/Kinetic3D.WebUI/src/components/storefront/ProductGrid.tsx
  </read_first>
  <action>
    1. Create `ProductCard.tsx`: Uses `react-parallax-tilt` for hover-only 3D tilt. Displays name, price (with strikethrough logic), category badge, flash sale badge, tagline, "Customize" CTA, and thumbnail.
    2. Create `ProductGrid.tsx`: A responsive CSS grid component that maps over an array of products and renders `ProductCard`s.
  </action>
  <acceptance_criteria>
    - `ProductCard.tsx` imports `Tilt` from `react-parallax-tilt`.
    - `ProductGrid.tsx` exists and renders a responsive grid (e.g., `grid-cols-1 sm:grid-cols-2 lg:grid-cols-4`).
  </acceptance_criteria>
</task>

<task id="assemble_pages">
  <description>Assemble the storefront pages</description>
  <read_first>
    - src/Kinetic3D.WebUI/src/app/layout.tsx
    - src/Kinetic3D.WebUI/src/app/page.tsx
    - src/Kinetic3D.WebUI/src/app/products/page.tsx
  </read_first>
  <action>
    1. Update `src/app/layout.tsx`: Import and include the `Header` component.
    2. Replace `src/app/page.tsx`: Include `HeroCarousel` and a `ProductGrid` with placeholder featured products.
    3. Create `src/app/products/page.tsx`: Include `ProductGrid` with placeholder products, and a sidebar for category/price range filtering.
  </action>
  <acceptance_criteria>
    - `src/app/layout.tsx` imports and renders `<Header />`.
    - `src/app/page.tsx` imports and renders `<HeroCarousel />`.
    - `src/app/products/page.tsx` exists and renders `<ProductGrid />` alongside a filtering sidebar layout.
  </acceptance_criteria>
</task>
```

## Verification
- `<Header>` and `<HeroCarousel>` render on the homepage without errors.
- Meilisearch triggers requests to `localhost:7700`.
- Product cards apply tilt effects smoothly on hover.

## Must Haves
- Cyber-Tech aesthetic with Obsidian Black and Cyan/Orange accents.
- Responsive design.
