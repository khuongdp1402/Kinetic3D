# Plan 02-01: Backend API CRUD and integrations

## Goal
Implement the REST APIs for Categories and Products, and integrate MinIO for presigned URLs and Meilisearch for search indexing via MediatR events.

</read_first>

`dotnet add src/Kinetic3D.Infrastructure/Kinetic3D.Infrastructure.csproj package AWSSDK.S3`
`dotnet add src/Kinetic3D.Infrastructure/Kinetic3D.Infrastructure.csproj package Meilisearch`
</action>

<description>Implement MinIO Storage Service</description>
<read_first>
- "src/Kinetic3D.Application/Common/Interfaces/IStorageService.cs"

</read_first>
<action>
Create `src/Kinetic3D.Infrastructure/Services/MinioStorageService.cs` implementing `IStorageService`.
Use `AmazonS3Client` with `AmazonS3Config { ServiceURL = "http://localhost:9000", ForcePathStyle = true }`.
Implement `GetPresignedUploadUrlAsync` using `GetPreSignedURLRequest` with `Verb = HttpVerb.PUT` and `Expires = DateTime.UtcNow.AddMinutes(15)`.
Register `IStorageService` in `DependencyInjection.cs`.
</action>
<acceptance_criteria>
- `MinioStorageService.cs` implements `IStorageService`.
- `DependencyInjection.cs` contains `services.AddScoped<IStorageService, MinioStorageService>()` (or Singleton).
</acceptance_criteria>
</task>
